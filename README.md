Yazar Web Projesi
Bu proje BLM2537-Ağ Tabanlı Programlamaya Giriş dersi kapsamında kişisel yazar web sitesi projesidir.
Proje İçeriği: Biyografi, kitaplık, etkinlik ve iletişim sayfalarından oluşan bir web sitesidir.
Kurulum ve Çalıştırma:
1- Bu projenin dosyalarını bilgisayarına klonlayın veya indirin.
2- Klasörü Visual Studio Code (VS Code) ile açın.
3- Live Server eklentisini kullanarak "index.html" dosyasını tarayıcınızda çalıştırın.
