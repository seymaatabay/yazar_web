Yazar Web Projesi
Bu proje BLM2537-Ağ Tabanlı Programlamaya Giriş dersi kapsamında kişisel bir yazar web sitesi olarak geliştirilmiştir.

Dosyayı Çalıştırma: Projedeki tüm dosyaları bilgisayarınıza indirin. index.html dosyasını herhangi bir web tarayıcısında açarak siteyi görüntüleyebilirsiniz.

İçerik

index.html: Ana sayfa

biyografi.html: Yazar hakkında bilgi

kitaplik.html: Eserler ve kitaplar sayfası

etkinlik.html: İmza günleri duyuruları

okurkosesi.html: İletişim bilgileri

style.css: Sayfanın tasarım ve stil dosyaları
